## NAME
strncmp - nonstrings compare

## LIBRARY
Standard C library (libc, -lc)

## SYNOPSIS
#include <string.h>

int strncmp(const char s1[], const char s2[], size_t n);

## DESCRIPTION
The strncmp() function is similar to strcmp(3), except it compares only the first (at most) n bytes of s1 and s2. It is equivalent to memcmp(s1, s2, MIN(MIN(strnlen(s1,n),strnlen(s2,n))+1, n)).

## RETURN VALUE
See memcmp(3).

## ATTRIBUTES
Interface: strncmp()
Attribute: Thread safety
Value: MT-Safe

## STANDARDS
C11, POSIX.1-2008.
