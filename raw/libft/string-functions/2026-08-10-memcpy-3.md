# memcpy(3) - Library Functions Manual

> Source: https://man7.org/linux/man-pages/man3/memcpy.3.html
> Collected: 2026-08-14
> Published: 2026-08-10

The memcpy() function copies n bytes from memory area src to memory area dest. The memory areas must not overlap. Use memmove(3) if the memory areas do overlap.

## NAME
memcpy - memory copy

## LIBRARY
Standard C library (libc, -lc)

## SYNOPSIS
#include <string.h>

void *memcpy(void *dest, const void *src, size_t n);

## DESCRIPTION
The memcpy() function copies n bytes from memory area src to memory area dest. The memory areas must not overlap. Use memmove(3) if the memory areas do overlap.

## RETURN VALUE
The memcpy() function returns a pointer to dest.

## ATTRIBUTES
Interface: memcpy()
Attribute: Thread safety
Value: MT-Safe

## STANDARDS
C11, POSIX.1-2008.

## HISTORY
POSIX.1-2001, C89, SVr4, 4.3BSD.

## CAVEATS
Failure to observe the requirement that the memory areas do not overlap has been the source of significant bugs. In glibc 2.13, a performance optimization on some platforms (including x86-64) changed the order in which bytes were copied from src to dest, revealing breakages in applications that performed copying with overlapping areas. In glibc 2.14, a versioned symbol was added so that old binaries employed an implementation that safely handles overlapping buffers (by providing an older memcpy() implementation that was aliased to memmove(3)).
